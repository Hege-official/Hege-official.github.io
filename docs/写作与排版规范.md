# 和各国新闻网站 · 内容写作与排版规范

> 适用范围：`_posts/` 目录下的全部文章。
> 正典来源：`D:\Desktop\和各共和国Republic of Hege\数字档案 - 和各维基资料库\Hegewiki\`（下文简称「正典库」）。
> 本规范只约束**网站这一侧**的写法；正典库自身的编辑规则以该库 `0_档案标准/档案编辑手册.md` 为准。

## 零、网站与正典的关系

| | 正典库（Hegewiki） | 本站（Jekyll 网站） |
|---|---|---|
| 角色 | 设定源、事实标准 | 面向公众的发布面、新闻门户 |
| 体裁 | 档案、法典、专题、会议记录 | 新闻、公告、社论 |
| 链接 | Obsidian 双链 `[[文档名]]` | 标准 Markdown 链接 / 站内 URL |
| 组织 | 7 个固定分类目录 | `categories` 决定栏目与 URL |

三条铁律：

1. **事实以正典为准**。机构名、法律名、人名、地名、纪年、数据，正典怎么写在网站就怎么写；网站可以换体裁、换语气，不能换事实。
2. **不得自造**。政府机构名必须能在正典《中央政会组成部门列表》中找到；数字必须来自正典《和各国民经济与社会数据数据库》或《5.人文与社会/社会数据/》；法律条文必须来自正典《4.宪法与法律/》。
3. **发现矛盾先记录，不擅自改**。正典库内部互相打架时，写进本文档第八节「待裁定」，由人工决定后再统一。

## 一、目录与命名

- 文章路径固定为 `_posts/YYYY-MM-DD-slug.md`。
- `slug` 用英文小写、`-` 连接，**尽量可读**（现状多为拼音缩写如 `hhjzxlrnunfbsm`，新文章建议向 `2026-08-hege-monthly` 这类可读形式靠拢，不强制回改旧文）。
- 日期 `YYYY-MM-DD` 取**新闻发布时间**，可以与正典文档的 `date_created` 不同（例如正典 8 月发布、网站 9 月转载）。
- 图片统一放 `assets/images/`，命名沿用正典附件规范：`[类型]-[对象]-[描述].[扩展名]`，如 `首都-艺宫-旧城改造.jpg`。禁止空格与特殊符号。
- 视频放 `assets/images/`（现状如此），文件名用英文，如 `Kuanian2026.mp4`。

## 二、front matter 规范

字段与默认值由 `_config.yml` 的 `defaults` 提供（`layout: single`、`author_profile: false`、`comments: false`、`related: true`、`publisher: "和各政府网"`），**这些无需在文章里重复写**。

```yaml
---
title: "文章标题"          # 必填。不出现栏目前缀也可，栏目由 categories 决定
excerpt: "一句话摘要"       # 必填。≤ 90 字，纯文本，禁止写 {{ }} 模板
date: 2026-08-11 09:00:00   # 必填。新闻发布时间
categories: [新闻]          # 必填。只能取：新闻 / 公告 / 社论 / 维护
tags: [新闻, 国内, 艺宫]     # 必填。中文，2–4 个，见第五节标签表
header:
  image: /assets/images/xxx.png   # 推荐。列表卡片缩略图与文章头图
publisher: "和各政府网"      # 可选。发布单位与默认不同时才写（如「和各日报」）
toc: true                   # 可选。长文/百科式条目开启
toc_label: "目录"
toc_icon: "bars"
infobox_header: "…"         # 可选。见第四节，百科式条目用
infobox_image: "…"
infobox_caption: "…"
infobox_data:
  - label: "…"
    value: "…"
---
```

栏目与 URL 的对应（`permalink: /:categories/:title/`）：

| categories | 栏目页 | 适合内容 |
|---|---|---|
| `新闻` | `/news/` | 要闻、政务动态、国际关系、地方 |
| `公告` | `/notices/` | 政令、通知、决议、法律公布、贺词 |
| `社论` | `/editorials/` | 社论、评论员文章、理论文章 |
| `维护` | — | 站务与说明，不上栏目页（如《和各国的基础了解与介绍》） |

## 三、栏目写作配方

四类文章的最小完整结构。**每篇至少回链 1–2 篇既有文章或正典实体**，把孤岛连成时间线。

### 1. 新闻（`新闻`）
```
导语（5W：谁 / 何时 / 何地 / 何事 / 何因）
→ 背景（这件事从哪来，回链旧文）
→ 关键引语（当事方原话，用引用块）
→ 数据与事实（用 embed_box 或表格）
→ 各方反应（金亦 / NUN / 各省…）
→ 影响与后续（预告下一篇）
→ 落款：发布单位 + 日期
```

### 2. 公告（`公告`）
```
标题（含文号，如「中央政会公告〔2026〕第 8 号」）
→ 依据（引用具体法律/组织法条文）
→ 分条正文（一、二、三…）
→ 附件 / 附表（可选，用表格）
→ 落款：机关全称 + 日期
说明：正文条款内**不出现**任何链接或 wiki 语法；需要引用其他文件时写全称。
```

### 3. 社论（`社论`）
```
标题（可带副标题）
→ 一个明确论点
→ 分论据（小标题组织）
→ 呼应近期具体事件 / 数据
→ 结尾展望
→ 落款：《和各月刊》评论员 / 《和各日报》评论员
```

### 4. 百科式条目（放 `维护` 或独立栏目）
沿用现有《艾伦·图灵》模板：`infobox` + 分级标题 + `embed_box` + 脚注来源 + 「参见 / 相关条目」。这类条目用于国家、机构、人物、专题总览（如从正典《和各共和国概况》改写的总览页）。

## 四、组件使用矩阵

| 内容 | 组件 | 语法 |
|---|---|---|
| 人物 / 机构 / 地区 / 条约的档案式信息 | `infobox` | front matter 写 `infobox_*`，正文首行 `{% include infobox.html %}` |
| 关键数据、概念解释、延伸阅读 | `embed_box` | `{% include embed_box.html title="…" icon="star" content="…" %}` |
| 政策解读、名词解释、随文提示（不浮动） | `content_box` | `{% include content_box.html title="…" icon="info-circle" content="…" %}` |
| 图片 + 图注 | `figure` | `{% include figure image_path="…" alt="…" caption="…" %}` |
| 视频（B 站 / YouTube / Vimeo / Google Drive） | `video` | `{% include video provider="bilibili" id="BV…" %}` |
| 本地视频文件 | 原生 `<video>` | 见《2026 新年贺词》内的响应式容器写法 |
| 消息来源、法律条文出处 | 脚注 | 正文 `[^1]`，文末 `[^1]: …` |
| 声明、提示、警告 | notice 类 | `<div class="notice--info">…</div>`，可选 `--warning/--success/--danger` |
| 数学公式 | MathJax | 正文首行 `{% include latex.html %}` |

组件不必每篇都用；**新闻类每篇至少用 1 个**（数据框或配图或引语），避免纯文本通稿感。

## 五、正典对接规则

### 5.1 双链怎么办
Obsidian 的 `[[文档名]]` 在 Jekyll 里**不会被解析**，一律改写成以下两种之一：

- **正文提及** → 用书名号/引号自然写：`…依据《和各国刑法》…`、`…在正典《木里民族保护规约》中…`
- **文末「相关条目 / 相关阅读」** → 用站内相对链接（`[标题](/新闻/xxx/)`）或正典条目名（不强行造链）。网站目前依靠 `related: true` 自动推荐，无需手写站内相关链接。

### 5.2 专名统一表

| 网站写法 | 正典对应 / 说明 |
|---|---|
| 和各国 | 国家简称，一般行文用这个 |
| 和各共和国 | 正式全称，仅在正式场合/文首全称时用 |
| 和各 | 形容词前缀，如「和各政会」「和各人民」 |
| 和各大小动物人民代表大会（动人代 / NAPC） | 最高权力机关，正式名以此为准 |
| 中央政会 | 最高行政机关 |
| 首都艺宫 | 首都（直辖市） |
| 金亦 | 山岛南金亦鞘翅共和国 |
| 摩国 | **和各特别行政区（一国两制）**，不是外国；不得写成外交对象 |
| 竦峙 | 金亦方组织，2024 年被缺席判决 |
| 202705 联邦 | 2018 年短暂存续的联邦时期 |

机构名必须取自正典《中央政会组成部门列表》：安全防卫部、外交部、民政部、设施部、工程部、文宣部、司法部、财政部、和各中央银行。

### 5.3 纪年与数据

- 纪年以公历为主，需要强调时用 `HY X年（YYYY年）`，如 `HY 7年（2024年）`。
- 任何统计数字（GDP 增速、CPI、失业率、人口、参保率等）必须来自正典数据文档，并在文末或脚注注明来源。
- 标签参考正典标签体系：#政治 #法律 #历史 #地理 #文化 #社会 #宪法 #刑法 #行政 #选举 #立法 #制度 #事件 #机构 #人物 #民族 #教育 #音乐 #国际关系 等。

## 六、写作与构建流程

1. 在正典库找对应文档，确认事实与称谓。
2. 定栏目（`categories`）→ 定 slug 与日期 → 选第三节配方。
3. 写 front matter（`excerpt` 用纯文本，不用模板）。
4. 写正文，按第四节插入组件。
5. 本地构建验证：`bundle exec jekyll build`（报错不清时加 `--trace`），检查 `_site/`。
6. 自检：图片文件确实存在于 `assets/images/`；视频路径正确；无 `[[ ]]` 残留；`excerpt` 无 `{{ }}`；专名与正典一致。
7. 提交推送，CI 自动发布到 `gh-pages`（见 `AGENTS.md`）。
   - 注意：本仓库无单元测试，**构建成功 = 验证通过**。

## 七、常见错误对照

| ❌ 错误 | ✅ 正确 | 说明 |
|---|---|---|
| 和国 | 和各国 | 国名简称 |
| 国微 | 国徽 | 同音错字 |
| 展现扩大会议 | 战线扩大会议 | 同音错字 |
| 艺官 | 艺宫 | 同音错字 |
| 最高行机关 | 最高行政机关 | 缺字 |
| 的的 / 了了 / 在在 / 月月始 | 的 / 了 / 在 / 开始 | 重复字 |
| 自造「某某委员会」 | 查部门列表后取用 | 不得编造机构 |
| 把摩国当外国搞外交活动 | 摩国是和各自治区域 | 一国两制 |
| 官方文件正文里写 `[[…]]` 或站内链接 | 正文写全称，链接只放文末 | 档案规范 |
| 直接粘贴正典原文 | 按网站体裁改写并配组件 | 发布面 ≠ 档案 |
| tags 留空 | 至少 1 个，建议 2–4 个 | 检索需要 |
